# Minecraft Bedrock 64×64 Skin Texture

Gothic Bedrock Skin is a 64×64 Minecraft skin texture for Bedrock Edition, featuring a dark gothic look with black hair, violet eyes, purple-trimmed clothing, silver details, and chunky boots.

## Install

1. Download `assets/textures/gothic_3d_skin.svg` from the project.
2. Convert the SVG to a 64×64 PNG using an SVG-compatible image editor or converter.
3. Import the PNG as a custom skin in Minecraft Bedrock Edition using the skin import options.

## Use

1. Open Minecraft Bedrock Edition and go to the Dressing Room.
2. Choose to create or edit a character, then select the option to import a skin.
3. Select the converted 64×64 PNG file.
4. Choose the classic model if prompted, then apply the skin.
